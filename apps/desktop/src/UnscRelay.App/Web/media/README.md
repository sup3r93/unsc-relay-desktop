# Media assets / Risorse multimediali

## English

Personal Halo audio and video assets are not distributed with the public sources. For a complete personal build, supply `startup.mp4`, `shutdown.mp4`, `startup-theme.mp3` and `background-theme.m4a` locally in this directory, using assets you are entitled to use. Git ignores these files. Source compilation and mocked UI tests do not require the tracks; building and validating the complete installer requires all expected media assets.

## Italiano

Le tracce Halo e i video personali non vengono distribuiti con i sorgenti pubblici. Per una build personale completa prepara localmente `startup.mp4`, `shutdown.mp4`, `startup-theme.mp3` e `background-theme.m4a` in questa cartella, usando risorse che puoi utilizzare. Sono ignorati da Git. La compilazione del codice e i test UI simulati non richiedono queste tracce. La creazione e la verifica dell’installer completo richiedono invece tutte le risorse previste.
