## English

Snapshot: 199 open alerts on `main` at source commit `b90252bc26470ed64d290dac958bdf17c33739bf`, after the previously approved 76 dismissals. Counts: 188 C# path-flow alerts, 5 C# process-start alerts, 2 JavaScript execution alerts and 4 vendor block-cipher alerts. 151 locations are test/smoke code, 44 product code and 4 vendored cipher internals. The table accounts for every snapshot ID once; line numbers refer to that scan.

This review does not dismiss any of these 199 alerts, disable a language/query, change scan configuration or weaken a branch rule. A scanner finding is a hypothesis: intentional local file selection and synthetic test roots must not be confused with a remote path traversal. No zero-alert or comprehensive penetration-test claim is made.

### Corrections and regression coverage

- Update backups now reject linked data/backup ancestors and linked allowlisted source files before creating output. Directory links and file links are exercised with synthetic data, verifying no writes or changed bytes outside the chosen tree.
- External editor launch requires an absolute existing EXE and passes one absolute literal filename. Remote copy names are prefixed/bounded and reject Windows streams, invalid names and control characters. This prevents ambiguous executable resolution and device/option-like scratch names; it does not prohibit the owner from intentionally selecting an editor.
- The Bash-follow harness no longer evaluates source text through `vm`. A JSON literal is parsed and compared with a pinned reviewed command; only that constant is executed. Bash selection is restricted to bundled Windows or fixed Unix system paths, startup hooks are cleared and execution is time-bounded. Both source parity and actual Bash output are checked.

### Residual contexts

All reported test writes use generated temporary roots or explicit synthetic loopback fixture roots supplied by the test runner. Smoke methods are explicitly enabled test entry points, not regular account/server inputs. Test process-start locations use fixed Windows system paths and literal argument lists. The table retains these alerts instead of silently suppressing them.

The four ECB warnings are in SSH.NET block primitives. `AesCipher.CtrImpl` applies the primitive to a changing counter, then XORs the keystream; `BlockImpl` delegates chaining to its `CipherMode`; `BclImpl` receives the selected mode (no ECB SSH transport offered). The legacy TripleDES block implementation is under `#if !NET`; it is not part of the net10 build. Replacing these primitives blindly would break protocol cryptography. Vault and recording encryption use authenticated AES-GCM independently. The actual vendored AES-CTR and AES-CBC implementations are checked against two-block NIST SP 800-38A Appendix F vectors (including counter carry), repeated-block behavior and the negotiated cipher list. Source: https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication800-38a.pdf . No vendor cipher code or algorithm policy is changed to hide a warning.

## Italiano

Esaminati tutti i 199 avvisi dello snapshot, senza chiuderli in massa e senza disattivare controlli. Sono 188 segnalazioni sui percorsi, 7 sugli avvii di processi/codice e 4 sulle primitive crittografiche della libreria SSH. 151 riguardano prove e dati sintetici, 44 il prodotto e 4 la libreria inclusa. La tabella precedente riporta tutti gli ID, i percorsi e le motivazioni verificabili.

Rafforzati i backup contro collegamenti a file/cartelle esterni, la risoluzione del programma editor e i nomi delle copie locali dei file remoti. Il test Bash non valuta più codice letto dal repository: confronta un valore JSON con un comando fissato, usa eseguibili previsti e un limite di tempo. Le prove dei collegamenti verificano anche che i dati esterni restino intatti. Non viene dichiarata protezione assoluta contro un altro processo ostile con gli stessi privilegi Windows.

Gli avvisi sulle primitive ECB richiedono il contesto: sono blocchi usati internamente per costruire CTR/altri modi SSH, non la cifratura dell’archivio. Quella TripleDES segnalata è esclusa dalla compilazione net10. Archivio e registrazioni usano AES-GCM. Nessuna query, lingua, protezione o segnalazione è stata rimossa per rendere verde il risultato.
