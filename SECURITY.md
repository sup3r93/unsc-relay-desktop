# Security / Sicurezza

## English

Use [private vulnerability reporting](https://github.com/sup3r93/unsc-relay-desktop/security/advisories/new) for suspected security flaws. Do not open public issues containing exploit details, credentials, SSH private keys, vault data or access tokens. Provide a sanitized description, affected version, impact and reproduction steps. No response-time SLA is promised.

Keep Windows and dependencies updated. A signature identifies a publisher; it does not guarantee that software is harmless. Personal self-signed certificates are not automatically trusted by Windows. Public source does not authorize access to any remote system.

## Italiano

Usa la [segnalazione privata delle vulnerabilità](https://github.com/sup3r93/unsc-relay-desktop/security/advisories/new) per sospetti problemi di sicurezza. Non aprire issue pubbliche con dettagli di attacco, credenziali, chiavi SSH private, archivi o token. Fornisci descrizione anonimizzata, versione interessata, impatto e passaggi per riprodurre. Non viene promesso un tempo di risposta.

Mantieni aggiornati Windows e dipendenze. La firma identifica un firmatario, ma non garantisce che un software sia innocuo. I certificati personali autofirmati non sono automaticamente attendibili per Windows. Il codice pubblico non autorizza l’accesso a sistemi remoti.
