# Security / Sicurezza

## Italiano

Non pubblicare vulnerabilità con credenziali, chiavi, archivi o dettagli di produzione. Per segnalazioni riservate utilizzare la segnalazione privata di vulnerabilità di GitHub quando disponibile, altrimenti contattare il titolare senza includere segreti. Il codice pubblico non costituisce un’autorizzazione ad accedere ai servizi del titolare. Non eseguire test con account o dati reali.

## English

Do not disclose credentials, keys, vaults or production details in vulnerability reports. Use GitHub private vulnerability reporting when available; otherwise contact the owner without including secrets. Public source code does not authorize access to the owner's services. Do not test with real accounts or personal data.
