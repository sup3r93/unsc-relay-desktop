# Contributing / Contribuire

## Italiano

Usare solo `main` e `dev`. Sviluppare e verificare su `dev`, poi aprire una pull request verso `main`. `main` richiede i controlli aggiuntivi e una revisione; `dev` richiede i controlli di base. Non creare release beta o prerelease. I commit devono essere scritti in inglese. Ogni README deve contenere le sezioni `## Italiano` e `## English`, aggiornate insieme. Non includere dati personali, credenziali, chiavi private o log di produzione. Le release e i deploy richiedono un’azione esplicita del titolare e non sono avviati da queste pipeline.

## English

Use only `main` and `dev`. Develop and verify on `dev`, then open a pull request targeting `main`. `main` requires additional checks and review; `dev` requires the baseline checks. Do not create beta or prerelease distributions. Write commit messages in English. Every README must include `## Italiano` and `## English`, updated together. Never commit personal data, credentials, private keys or production logs. Releases and deployments require an explicit owner action and are not triggered by these workflows.
